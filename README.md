# Pequeños Guerreros, Grandes Valores

Presentación web horizontal para la muestra de Taekwondo infantil del Jardín Jorgito y sus amigos con apoyo del Club Gajog.

## Ver localmente

Abrir `index.html` directamente en el navegador.

## Publicación en GitHub Pages

Este proyecto está preparado como sitio estático. Para publicarlo en GitHub Pages:

1. Entrar a la configuración del repositorio en GitHub.
2. Ir a `Settings > Pages`.
3. Seleccionar `Deploy from a branch`.
4. Elegir la rama `main` y la carpeta `/root`.
5. Guardar.

El sitio usa:

- `index.html`
- `styles.css`
- `script.js`
- `IMAGENES/`
- `LOGO GAJOG-192x192.png`
- `jorgitoysusamigos.png`
